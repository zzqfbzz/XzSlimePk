# XzPk

在《我的世界》（Java 版）里批量寻找史莱姆区块的工具：你圈一个大范围，
程序找出其中 **8×8 区块（=128×128 格）窗口**里史莱姆区块**最多/最少**的位置（各 topK 条），
方便圈地做史莱姆农场或避开史莱姆区块。判定公式与游戏**官方一致**。

## 当前版本：V3（图形界面版，推荐）

入口只有一个，双击运行即可：

```bat
v3\gui.bat        # 编译并启动图形界面（主要入口）
v3\selftest.bat   # 编译并运行内置自检（可选，见下方说明）
```

界面特点：
- 世界种子、范围需**手动填写**；窗口大小默认 **8**、输出条数 topK 默认 **50**（均可改），
  坐标单位（方块/区块，自动换算）下拉可选；
- 两种计算模式：`sliding`（窗口可放在范围内任意区块，推荐，找最优）
  与 `grid`（从范围左上角每隔窗口大小铺互不重叠的格子）；
- 窗口只需左上角锚点区块在范围内，可向右/下**溢出**范围边缘；
- 多线程扫描，结果只保留最多/最少各 topK 条，输出可整行复制，也可一键 **“导出为 TXT”**
  保存到当前目录（文件名含种子，内容含种子与坐标）。

详细说明见 **[v3/README.md](v3/README.md)**。

### selftest 是干嘛的

`Selftest` 是无第三方依赖的**自检程序**（双击 `v3\selftest.bat` 运行），
用"暴力直接数"等独立方式**交叉验证引擎没算错**，改代码后跑一遍能立刻发现回归：

- 判定公式：与 Minecraft Wiki 官方写法逐坐标对照（4 万随机坐标）+
  真实回归用例（某种子大坐标窗口必须 =11 个史莱姆区块）；
- 方块↔区块坐标换算边界（负数向下取整）；
- grid / sliding 结果 vs 暴力逐窗口重数（含负坐标、溢出到范围外、skip=2、非对称范围）；
- 同一输入跑两次结果是否确定。

输出如 `全部自检通过, 共 44380 项检查 OK` 即正常；某一步失败会报出错位置。
