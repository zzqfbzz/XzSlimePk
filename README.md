# XzPk

《我的世界》（Java 版）史莱姆区块扫描工具：划一个大范围，找出其中
**8×8 区块（=128×128 格）窗口**里史莱姆区块**最多**（适合建史莱姆农场）和
**最少**（想避开）的位置，各保留 topK 条。判定公式与游戏**官方一致**。

## 使用

```bat
gui.bat        # 双击：编译并启动图形界面（主要入口）
启动.bat       # 与 gui.bat 相同，双击启动
selftest.bat   # 双击：编译并运行内置自检（可选）
```

界面里填写参数后点“开始扫描”，结果输出在下方文本区；扫描完成后点
**“导出为 TXT”** 会把完整报告（含种子与坐标）保存到程序当前目录，
文件名 `史莱姆区块结果_种子<seed>.txt`。

## 界面参数

| 控件 | 说明 |
|---|---|
| 计算模式 | `sliding(滑动窗口, 推荐)` = 范围内每个区块都可作窗口左上角，找任意摆放最优；`grid(从角点铺格)` = 从范围左上角起每隔窗口大小铺互不重叠的格子 |
| 坐标单位 | `方块坐标(游戏F3)`（推荐，自动 ÷16）或 `区块坐标` |
| 世界种子 | 游戏内 `/seed` 的值，**手动填写** |
| 范围 | 两个角点：起点 (x,z) ~ 终点 (x,z)，按所选单位填，**手动填写** |
| 窗口大小 | 默认 `8`（单个玩家可加载的最大区域 = 8×8 区块 = 128×128 格），可改 |
| 输出条数 | 默认 `50`（最多/最少各保留多少条），可改 |

## 关键语义

- **窗口只需左上角锚点区块在范围内**，可向右/下**溢出**范围边缘，超出部分照常统计满 64 格
  （例：方块范围 0~100 → 锚点 0,16,…,96 共 7 个）。
- **坐标换算**：方块坐标 ÷16 向下取整得区块坐标（负数也正确）。
- **输出行**：`数量|x,z=世界方块坐标|X,Z=起点区块坐标|WxW|占比`
  - 例：`18|x,z=-144,-320|X,Z=-9,-20|8x8|28.1%`
- 结果**只保留最多/最少各 topK 条**（有界堆逐条比较插入），不保存全部窗口；
  多线程分片，扫描上亿候选窗口也只要 1~2 秒。

## 判定公式（与 Minecraft 官方一致）

依据 [Minecraft Wiki](https://minecraft.wiki/w/Slime)，各坐标项先按 **32 位 int 运算**
（溢出回绕）再与种子相加，最后异或掩码：

```java
hash = seed + (int)(chunkX*chunkX*0x4c1906) + (int)(chunkX*0x5ac0db)
             + (int)(chunkZ*chunkZ)*0x4307a7L + (int)(chunkZ*0x5f24f);
hash ^= 0x3ad8025fL;
new Random(hash).nextInt(10) == 0   → 史莱姆区块（概率 10%）
```

注意：旧版曾用“全程 long”写法，区块坐标超过约 ±20 即与真实游戏不一致
（例：种子 `-2870327070709450083`，NW 方块 `(93696,-192)` = 区块 X5856~5863 Z-12~-5：
long 写法数 24，官方应为 **11**）。该窗口已作为自检回归用例。

## selftest 是干嘛的

`Selftest` 是无第三方依赖的**自检程序**（双击 `selftest.bat`），用暴力直接数等独立方式
交叉验证引擎没算错，改代码后跑一遍可立刻发现回归：

- 判定公式与 Wiki 官方写法逐坐标对照（4 万随机坐标）+ 真实回归窗口（必须 =11）；
- 方块↔区块换算边界（负数向下取整）；
- grid / sliding vs 暴力逐窗口重数（负坐标、溢出、skip=2、非对称范围等）；
- 同一输入两次运行结果是否确定。

输出 `全部自检通过, 共 44380 项检查 OK` 即正常。

## 目录结构

```
XzPk/
├─ README.md
├─ gui.bat / 启动.bat   # 编译并启动图形界面
├─ selftest.bat        # 编译并运行自检
├─ .gitignore
└─ src/xzpk/           # Java 源码（包 xzpk）
   ├─ Gui.java          # 图形界面（输入框 + 开始按钮 + 输出区 + 导出 TXT）
   ├─ Config.java       # 内存配置 Builder 与校验（无文件/无隐藏默认）
   ├─ SlimeChunk.java   # 史莱姆区块判定（官方 int 语义）
   ├─ GridScanner.java  # grid 模式（从角点铺格，多线程）
   ├─ SlidingScanner.java # sliding 模式（滑动窗口 + 滑窗优化，多线程分片）
   ├─ TopKCollector.java # 有界 Top-K 收集器（内存 O(K)，逐条比较插入）
   ├─ ResultItem.java / ScanResult.java / Output.java / ProgressBar.java
   └─ Selftest.java     # 无框架自检
```

（编译产物输出到 `out/`，已被 .gitignore 忽略。）
